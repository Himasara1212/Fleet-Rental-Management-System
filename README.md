# Fleet Rental Management System (FRMS)

A terminal-based Fleet Rental Management System built in Java, using core Object-Oriented Programming principles.

---

## 📋 Project Overview

FRMS is a lightweight, console-based application for a small vehicle rental company. It allows registered users to manage vehicles, customers, and rental agreements through a simple menu-driven interface.

The system demonstrates core OOP concepts including:
- Inheritance
- Abstraction
- Encapsulation
- Polymorphism
- Composition / Association
- Enums (including a rich enum)
- Interfaces (including a functional interface)
- Custom checked exceptions
- Multithreading with daemon threads
- Java Collections

---

## 🛠️ Requirements

- **Java JDK 25 or later** (JDK 25+)
- Any Java IDE (IntelliJ IDEA, Eclipse, NetBeans) or a plain text editor with `javac`
